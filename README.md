# Password Reset Ticket — Active Directory Documentation

Here, I replicated receiving a ticket for a user who had forgotten their password and was locked out of their account.

![Ticket received]([media/image2.png](https://github.com/lorentzbissereth-arch/TicketResponseLab/blob/d050dff17fc20315de7c7682067ab1dffc55b919/image2.png))

## Locating the User

Here, I located the user in Active Directory by right-clicking on `lolo.local`, then clicking **Find**.

![Locating the user](media/image1.png)

## Resetting the Password

Here, I reset the password for the user, unlocked the user's account, and gave it a strong password by right-clicking on the user and selecting **Reset Password**.

![Resetting the password](media/image6.png)

Here, the password reset is shown to be successful.

![Successful reset](media/image3.png)

## Confirming with the User

Here, I checked back with the user to make sure they were satisfied.

![Confirming with user](media/image5.png)

I then closed the ticket to clear up space in the ticket manager.

![Closing the ticket](media/image4.png)

## Summary

In this project, I demonstrate an understanding of some of the main technical skills needed for a Tier 1 Helpdesk role. I successfully demonstrated opening a ticket inside the Spiceworks ticketing system and responding to the ticket request. I showcased technical skills inside the Active Directory environment by locating the user, unlocking the account, and resetting the password.
